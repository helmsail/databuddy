# 业务规则说明书(订单域)

> 适用范围:biz_demo 演示业务库。任何涉及订单、营收、退款的分析都必须遵循本文口径。

## 一、订单状态

| 状态 | 含义 | 是否计入营收 |
|---|---|---|
| 已支付 | 客户完成支付且未发生退款 | 计入 |
| 已退款 | 支付后发生全额退款 | 不计入 |

- 状态存储在 `orders.status` 字段,中文枚举。
- 退款订单**保留**在订单流水中,用于退款率与渠道质量分析,不可从分析中直接丢弃。

## 二、金额口径

- `orders.amount` 为**实付金额**(已含数量与折扣):`amount ≈ quantity × unit_price × 折扣系数`。
- 分析营收时一律对 `amount` 求和;不要用 `quantity × unit_price` 估算(会忽略折扣、系统性高估)。
- 历史促销折扣区间为原价的 90%~110% 浮动(部分产品存在溢价销售)。

## 三、退款规则

- 订单支付后 30 天内可全额退款,退款后状态变为「已退款」。
- 退款率口径:退款率 = 已退款订单数 ÷ 全部订单数。
- 退款率超过 8% 时,需要在分析结论中显著提示。

## 四、渠道定义

| 渠道 | 说明 | 特征 |
|---|---|---|
| 线上广告 | 信息流 / 搜索广告直接成交 | 订单量最大 |
| 线下门店 | 实体门店导购下单 | 客单价中等 |
| 合作伙伴 | 渠道商 / 代理商批量订单 | 单笔金额高 |
| 直播带货 | 直播间专属链接成交 | 波动大、集中爆发 |

- 渠道分析必须同时呈现**订单数**与**金额**两个口径,两者的排名可能不一致。

## 五、客户与地域

- 客户为 B 端企业客户,`customer_name` 为企业全称,`city` 为注册地城市。
- 新客 / 老客按首单时间区分:统计期内首次下单为「新客」,其余为「老客」。
- 城市维度分析以客户注册地(customers.city)为准,而非收货地。

## 六、常用建议

- 环比/同比:按 `order_time` 按月聚合,对比前一自然月。
- 演示数据时间范围:2026-03-01 起共约 180 单,覆盖 4 个渠道、6 个产品、8 个客户。
