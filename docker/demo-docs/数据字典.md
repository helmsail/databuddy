# 数据字典(演示业务库 biz_demo)

> 三张表:orders(事实表)+ customers / products(维度表)。金额单位均为人民币元。

## customers 客户表

| 字段 | 类型 | 含义 | 备注 |
|---|---|---|---|
| id | BIGINT | 客户ID | 主键 |
| customer_name | VARCHAR(64) | 客户名称 | B 端企业全称 |
| city | VARCHAR(32) | 城市 | 注册地城市 |
| register_time | DATETIME | 注册时间 | 北京时间 |

## products 产品表

| 字段 | 类型 | 含义 | 备注 |
|---|---|---|---|
| id | BIGINT | 产品ID | 主键 |
| product_name | VARCHAR(64) | 产品名 | 含型号后缀 |
| category | VARCHAR(32) | 品类 | 智能硬件 / 数码配件 / 可穿戴 / 智能家居 |
| unit_price | DECIMAL(10,2) | 单价(元) | 挂牌价,实际成交以订单金额为准 |

## orders 订单表(核心事实表)

| 字段 | 类型 | 含义 | 备注 |
|---|---|---|---|
| id | BIGINT | 订单ID | 主键 |
| customer_id | BIGINT | 客户ID | 外键 → customers.id |
| product_id | BIGINT | 产品ID | 外键 → products.id |
| quantity | INT | 数量 | 单笔 1~5 件 |
| amount | DECIMAL(12,2) | 订单金额(元) | **实付金额**,已含折扣 |
| channel | VARCHAR(32) | 来源渠道 | 线上广告 / 线下门店 / 合作伙伴 / 直播带货 |
| order_time | DATETIME | 下单时间 | 北京时间 |
| status | VARCHAR(16) | 状态 | 已支付 / 已退款 |

## 表间关系

- `orders.customer_id` → `customers.id`(N:1,一个客户可有多笔订单)
- `orders.product_id` → `products.id`(N:1,一个产品可出现在多笔订单)

## 使用说明

- 时间字段均为北京时间(DATETIME,无时区)。
- 订单表是唯一包含金额的表;客户 / 产品维度的金额指标必须经 orders 关联聚合。
- 涉及「营收」的口径见《业务规则说明书》和《运营指标口径手册》。
